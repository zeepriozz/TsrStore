# 🏪 TSR Store — Local Marketplace App for Thrissur

**TSR Store** is an Android-based online marketplace designed to connect **local shops in Thrissur** with nearby customers.  
The app empowers small businesses to list, promote, and sell their products locally — making shopping simple, fast, and community-driven.

---

## 📱 Features

- 🔐 **OTP-Based Login:** Secure user authentication using OTP verification.
- 🧍 **Session Management:** User details (name, phone) auto-filled using SessionManager.
- 🛒 **Cart Management:** Add, remove, and buy products directly from the cart.
- 🛍️ **Product Listing:** View and explore products categorized under:
  - Home Appliances
  - Kids
  - Elder
- 🧾 **Order Management:** Track and manage orders efficiently.
- 🔎 **Search Functionality:** Search for products across multiple categories.
- 🏪 **Seller Login:** Dedicated seller panel for product uploads and management.
- 🖼️ **Image Loading:** Product images are fetched and displayed using **Picasso**.
- ⚙️ **Persistent Login:** Users remain logged in until they explicitly log out.

---

## 🧰 Tech Stack

| Layer | Technology |
|-------|-------------|
| **Frontend** | Android (Java / migrating to Kotlin) |
| **UI Design** | XML, CardView, RecyclerView |
| **Backend** | PHP + MySQL *(planned migration to Firebase or modern backend)* |
| **Networking** | Volley Library |
| **Image Handling** | Picasso |
| **Authentication** | Firebase OTP |
| **Session Management** | Custom SessionManager class |
